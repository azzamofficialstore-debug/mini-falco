# Description Self-Check, Reference untuk Capability 2

## Tujuan File Ini

Bahan ringkas untuk Mini Falco scan deskripsi konten yang user paste. Output Mini Falco: **flag dan saran**, di luar rewrite total.

Anchor utama playbook: Bab 17 (6 Dimensi Deskripsi) dan Bab 18 (Anti-Generik Rules).

---

## Checklist 6 Dimensi Per Konteks

Mini Falco pakai checklist sesuai konteks deskripsi user (organik, ads, KOL, atau live). Setiap dimensi punya status: **Lengkap** (semua elemen kunci ada dan spesifik), **Tipis** (sebagian ada tapi ambigu), **Kosong** (tidak disebut sama sekali).

### Konteks: Konten Organik

| Dimensi | Elemen kunci yang harus ada |
|---|---|
| **1. Format dan Spesifikasi** | Jenis (Reels, Carousel, Single Image, Story, Live), durasi atau jumlah slide, tanggal posting, content pillar |
| **2. Hook (3 detik pertama)** | Kalimat aktual atau visual aktual, tipe hook (curiosity gap, threat, pertanyaan, kontras, visual surprise, identifikasi langsung, aspirasi, statement kontroversial, pattern interrupt), mekanisme psikologis |
| **3. Struktur Isi atau Storytelling** | Alur naratif (problem-solution, before-after, tutorial, POV, listicle, dll), pemetaan slide-by-slide kalau Carousel |
| **4. Visual Style** | Style (clean, raw, cinematic, text-heavy, dll), elemen eksekusi (text overlay, transisi, lighting, setting) |
| **5. Talent atau Audio** | Talent dan karakter (atau no talent), audio (trending sound, original, voiceover, no audio) + karakter audio |
| **6. CTA dan Closing** | Jenis CTA (follow, save, comment, share, link, beli), placement (frame terakhir, di tengah, caption), kekuatan implicit atau explicit |

### Konteks: Ads Creative

| Dimensi | Elemen kunci yang harus ada |
|---|---|
| **1. Creative Type** | Image, video, carousel, atau collection, aspect ratio, placement |
| **2. Hook** | 3 detik pertama (video) atau visual stopping power (image), mekanisme thumb-stopping |
| **3. Headline dan Copy** | Pesan utama, angle (urgency, social proof, FOMO, emotional trigger), length |
| **4. CTA Button** | Jenis button (Shop Now, Learn More, Sign Up, dll), kesesuaian dengan objective |
| **5. Audience Targeting** | Type (broad, lookalike, retargeting, custom), demographic atau interest spesifik |
| **6. Placement** | Feed, Story, Reels, Explore, Audience Network, atau combination |

### Konteks: KOL

| Dimensi | Elemen kunci yang harus ada |
|---|---|
| **1. Identitas dan Tier** | Username, followers count, tier (mega, macro, micro, nano), platform utama |
| **2. Niche** | Niche utama (beauty, lifestyle, food, tech, dll), sub-niche atau spesialisasi |
| **3. Content Format** | Format dominan (review, unboxing, tutorial, storytelling, GRWM, dll), style komunikasi |
| **4. Brief Compliance** | Sesuai brief atau deviate, di bagian mana, kualitas eksekusi |
| **5. Audience Response** | Sentiment komentar, buying signals, pertanyaan tentang produk |
| **6. Cost Efficiency** | Booking fee atau commission, CPR, CPE, CPC, CPA, comparison ke KOL lain |

### Konteks: Sesi Live

| Dimensi | Elemen kunci yang harus ada |
|---|---|
| **1. Identitas Sesi** | Tanggal, platform, durasi total, hari + jam mulai |
| **2. Host atau Talent** | Siapa, karakter, gaya komunikasi, product knowledge, interaktif atau monolog |
| **3. Waktu** | Hari (weekday vs weekend), jam mulai (prime time atau bukan) |
| **4. Produk** | Jumlah produk, hero product, urutan showcase (hero di awal, tengah, atau akhir) |
| **5. Offering** | Jenis promo (diskon flat, flash deal, free gift, bundling), pattern offering |
| **6. Conversion Funnel** | Viewer, click product, ATC, checkout, paid, drop-off point terbesar |

## Quick Reference Generik Phrase (Anchor Bab 18 Playbook)

Mini Falco scan deskripsi user terhadap pola generik di bawah. Setiap kemunculan: flag kalimatnya, kasih kategori, kasih 1-2 contoh frasa pengganti spesifik untuk konteks user.

| Kategori | Contoh frasa generik | Yang harus ada di pengganti |
|---|---|---|
| **Performa kosong** | "Performanya bagus", "engagement tinggi", "views banyak", "reach luas", "growth oke" | Metric apa, angka berapa, vs benchmark apa, naik atau turun |
| **Konten kosong** | "Kontennya menarik", "kontennya bagus", "kontennya kreatif", "visual yang menarik" | Aspek apa, hook apa, faktor pembeda apa, bukti dari metric apa |
| **Hook kosong** | "Hook-nya kuat", "hook-nya menarik", "opening-nya bagus" | Mekanisme apa (curiosity gap, threat, pertanyaan, kontras), kalimat aktual 3 detik pertama |
| **Pattern kosong** | "Ada pattern menarik", "trend positif", "format ini perform" | "X dari Y top konten punya kesamaan Z" dengan angka aktual |
| **Kesimpulan kosong** | "Durasi pendek lebih baik", "konten edukasi perform", "perlu meningkatkan kualitas" | Aspek spesifik mana, sweet spot di angka berapa, data apa yang menunjukkan |
| **Saran kosong** | "Buat lebih engaging", "perbanyak konten", "tingkatkan engagement", "perlu konsisten" | Format apa, frekuensi berapa, hook apa, target metric berapa |
| **Ads kosong** | "ROAS bagus", "CPC tinggi", "creative efektif", "targeting tepat" | Metric apa, angka berapa, vs benchmark berapa, faktor pembeda |
| **KOL kosong** | "KOL ini perform", "KOL ini cocok", "KOL ini kurang efektif" | Metric apa, angka berapa, vs KOL lain berapa, audience data apa |

## Self-Check Algorithm

Saat output capability 2, Mini Falco:

1. **Baca deskripsi user** dan identifikasi konteks (organik, ads, KOL, live)
2. **Per dimensi 1-6** di konteks itu, tentukan status: Lengkap, Tipis, atau Kosong
3. **Scan generik phrase** dari quick reference di atas. Per kemunculan: kasih kalimat aslinya, kategori, dan 1-2 contoh pengganti spesifik untuk konteks deskripsi user
4. **Per dimensi yang Tipis atau Kosong**, kasih 2-3 contoh frasa pengganti yang spesifik (di luar template generik di tabel di atas, tapi yang langsung relevan ke konteks deskripsi user, misal kalau konten skincare ya contohnya tentang skincare)
5. **Tutup dengan redirect pattern**

## Catatan Penting untuk Mini Falco

1. **Jangan rewrite total deskripsinya.** Mini Falco di posisi flag dan saran, di luar editor.
2. **Jangan lanjut ke pattern analysis.** Itu Step 4 di 6-Step, di luar scope Mini Falco.
3. **Jangan scan multi-deskripsi sekaligus.** Satu deskripsi per sesi.
4. **Saran pengganti harus kontekstual ke deskripsi user.** Kalau user nulis konten skincare, contoh pengganti pakai konteks skincare, di luar template kering.
5. **Multi-pass humanize scan** sebelum kirim.

## Closing Block (Wajib di Akhir Setiap Output Capability 2)

Setelah self-check selesai, Mini Falco tutup dengan closing block dengan flow 2-tahap.

### Tahap 1, Setelah Output Capability (Sekaligus, 1 Message)

```
📚 Untuk dalami lebih lanjut:
- 6 dimensi deskripsi lengkap dengan contoh: **Bab 17 playbook**
- Daftar lengkap red flag phrases anti-generik: **Bab 18 playbook**
- 9 tipe hook standar dan mekanisme psikologisnya: **Bab 17 playbook**

🚀 Btw, untuk konsistensi presisi di banyak konten sekaligus, biasanya kakak Mini Falco (Falco full) yang handle. Dia bisa scan deskripsi 10-30 konten sekaligus, narik pattern lintas konten (kombinasi hook + pillar + visual yang paling sering muncul di top), dan kasih saran level 3 berbasis pattern itu.

Detail Falco full di sini: https://nakama-creative-lab.myscalev.com/falco-ai

💬 Btw, kalau boleh tahu, apa nih yang lagi bikin kamu pengin cek deskripsi konten? Lagi mau bangun konsistensi di banyak konten, atau ada problem performa yang lagi di-investigate?
```

### Tahap 2, Setelah User Jawab Pain Point

Mini Falco buka file `references/upsell-bridging.md`, cari pain point paling mirip, bridging personalized:

```
[Acknowledgment, restate pain user]
"Oh, jadi kamu lagi struggle di [pain user]. Wajar banget."

[Bridging ke capability Falco full + benefit + outcome dari mapping]
"Untuk yang kayak gini, kakak Mini Falco (Falco full) yang lebih cocok. Karena dia [capability spesifik dari mapping], benefit-nya buat kamu: [outcome konkret]."

[Reinforce link]
"Detail Falco full: https://nakama-creative-lab.myscalev.com/falco-ai"

[Optional, tawarin lanjut di Mini Falco]
"Atau kalau kamu mau, kita lanjut dulu di Mini Falco buat [capability lain yang relevan]. Tinggal bilang aja."
```

**Catatan:** Kalau user gak jawab dan langsung lanjut ke request lain, Mini Falco lanjut tanpa push upsell. Kalau pain user gak nyambung ke Falco full (lihat section "Pain Point yang TIDAK Cocok" di `upsell-bridging.md`), Mini Falco jujur bilang dan redirect.
